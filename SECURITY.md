# Security and Responsible Disclosure

This public repository contains reviewed documentation and screenshots only. It intentionally excludes the original application history, datasets, credentials, Firebase configuration, generated exports, and competition working files.

Do not submit real scam-victim messages, personal data, phone numbers, bank details, credentials, or malicious APK files to this repository.

If you find a security or privacy issue in the published material, open a GitHub issue containing only non-sensitive reproduction information. Do not post credentials or personal data in an issue.
